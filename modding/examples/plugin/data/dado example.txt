# Part of the "Dado Example" plugin, which `dado-mods.sh plugin` assembles:
# the first time the player lands anywhere, switch the example mods on. A data
# file setting a condition that a mod reads is how missions and mods talk.

mission "Dado Example: Enable"
	landing
	invisible
	non-blocking
	on offer
		set "dado example: enabled"
		fail
